# 2026 ARC Washington DC Trip

Trip itinerary for the 2026 American Rocketry Challenge National Finals, May 14–17, 2026 in Washington DC / Northern Virginia.

## View the itinerary

The trip plan is a single-file interactive HTML page: [`index.html`](./index.html)

Once GitHub Pages is enabled, it will be live at:

**https://lhp620.github.io/2026ARCWashingtonDCTrip/**

## Contents

- **Thursday, May 14** — DC sightseeing day (Air & Space Museum, Capitol, Library of Congress, monuments walk)
- **Friday, May 15** — ARC Welcome & Team Briefing at Metz Middle School, evening strategy session
- **Saturday, May 16** — ARC National Finals fly-off day at Great Meadow
- **Sunday, May 17** — Return flight home from IAD

Plus a reference section summarizing the official ARC Finals Procedures (students-only rule, launch windows, returns deadlines, DQ risks, rocket design rules, etc.).

## Enabling GitHub Pages

1. Go to the repository **Settings** → **Pages**
2. Under "Build and deployment", set **Source** to `Deploy from a branch`
3. Select branch `main` and folder `/ (root)`
4. Click **Save** — the site will publish in a minute or two
